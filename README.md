# Вечерние новости, коллеги!

Сайт: https://arslongavita.github.io/vechernie-novosti/

Автоматический выпуск запускается в GitHub Actions ежедневно в 17:00 UTC (20:00 МСК). GitHub может задерживать запуск; точная минута не гарантируется.

update_news.py собирает русскоязычные RSS Google Новостей за последние 24 часа, группирует похожие темы, учитывает число изданий и позицию в ленте. Публичные каналы РБК и Коммерсанта в Telegram проверяются как дополнительные источники: посты добавляются только при совпадении с новостной темой. Это автоматическая подборка заголовков, а не редакторская проверка фактов или измерение вирусности.

В каждой категории ровно пять новостей. Если свежих данных недостаточно или RSS недоступен, задание завершается с ошибкой и сохраняет предыдущий выпуск. Изменения issue.json записываются в main, затем публикуются через Pages. Для ручной проверки: Actions → Daily news at 20 Moscow → Run workflow.

Открытая страница проверяет новый выпуск раз в минуту, когда вкладка видима. Токены и платные API не требуются; используются стандартные ограниченные права GitHub Actions в этом репозитории.
