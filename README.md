# Вечерние новости, коллеги!

Статический сайт GitHub Pages. Файлы index.html и issue.json размещаются в корне ветки main; в Settings → Pages выберите Deploy from a branch → main → /(root).

Автоматический сбор новостей пока не подключён. Выпуск обновляется заменой issue.json. В нём должно быть ровно пять новостей мира и пять России, с датой обновления и ссылками на проверенные источники.
